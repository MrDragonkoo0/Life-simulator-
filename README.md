# Life+ v0.14.0 — Big Content

## Додано
- 100+ автомобілів з орієнтовними цінами, паливом, станом, заправкою, ремонтом і продажем.
- 100+ варіантів оренди та купівлі житла, комфорт, комунальні та власність.
- 100+ бізнесів без прокачки: купив → працює.
- 200+ товарів магазину та інвентар.
- Їжа, одяг, техніка, меблі, інструменти, автотовари, розваги та інше.
- 100+ професій з 6 кар'єрними рівнями та зарплатами від стартових до топових.
- Щоденні, тижневі та довгострокові квести.
- XP, кар'єрні підвищення, досягнення та нагороди.
- Нові дані зберігаються через існуючу систему Railway Volume.
